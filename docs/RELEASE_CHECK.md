- GNU 官方 AGPLv3 原文、`AGPL-3.0-only` 元数据与源码声明一致；第三方原始许可另行保留。

## 发布范围和限制

仓库只准备源码，原生 DLL 由使用者按 README 编译。既有 PyInstaller EXE 的检测尚未定性，不随此次准备版本发布。

CI 已配置 Windows/Python 3.13/Node 22，第三方 Actions 固定到完整提交 SHA，默认只读仓库权限；远程 CI 要在上传后首次验证，不能以本机通过代替远程结果。

QQ 实机仅验证 README 指定构建；WPS 页面结构可能变化。没有对真实活动执行测试提交，也没有证明每个实际表单的重复填写行为。提交与录取分别核对。

尚未确定远程仓库名称和可见性；未创建仓库、推送代码或发布版本标签。建仓后建议启用私密漏洞报告、密钥扫描及分支保护。
