群活动助手首次公开源码版本，采用 GNU AGPLv3（AGPL-3.0-only）。

支持 QQ 活动通知解析、搜索与排序、人员档案、真实 WPS 字段读取、定时报名队列、活动取消处理、QQ/WPS 状态和全局刷新。

请下载源码 ZIP，按 README 安装依赖和编译原生组件；`SHA256SUMS.txt` 用于核对下载文件。GitHub 也提供该标签对应的源码下载。

此版本不包含 EXE/DLL。旧版 EXE 的 Defender 检测尚未定性；QQ 接收仅支持 Windows x64 QQ 9.9.35-52892。尚未通过真实志愿报名提交验证端到端成功，提交与录取分别核对。详细验证范围见 `docs/RELEASE_CHECK.md`。

个人档案和浏览器登录资料仅在本机保存，不在发布包内。
